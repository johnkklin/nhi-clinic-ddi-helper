# 診所健保雲端【肝腎警示・過敏史・DDI 交互作用】插槽感應助手 (5.x 專用版)

專為基層診所設計的輕量級輔助工具，整合 **「Windows 讀卡槽自動感應（本機 Python）」** 與 **「健保雲端 2.0 檢驗置頂助手（Chrome / Edge 外掛）」**，在不改動既有 HIS 系統、不搶佔讀卡機的前提下，實現處方前零點擊防呆把關。

---

## 一、 核心功能與看診動線

### 1. 診間「提早插卡、零點擊」自動把關（做法 A）
* **不增加插拔次數**：病人進診間（或護理師遞卡）時，順手將健保卡推進診間桌上的讀卡機槽內放著（取代原本批價寫卡時才插卡）。
* **Windows 底層插槽感應（0% 佔用讀卡機）**：透過 Windows 內建智慧卡服務（`WinSCard`）監聽卡槽狀態變化，平時完全不連線讀卡機、不與 HIS 系統衝突。
* **全綠靜默、有異常才置頂攔截**：卡片推入緩衝 2 秒後自動於背景完成查詢。若全部正常，視窗保持縮小不干擾看診；一旦偵測到 **CKD 腎功能異常／洗腎、近 3 個月 C 肝陽性、雲端藥物過敏史、常用藥交互作用 (DDI)**，立刻發出提示音並自動彈出置頂 4 秒。
* **批價寫卡不二次打擾**：內建同病人 5 分鐘防重複查詢；看診結束按 HIS 寫卡時卡片已在槽內直接寫入，不會重複跳窗。若維持「最後寫卡才插卡」的習慣，寫卡佔線時會自動延遲 2.8 秒重試，趕在病人領藥前攔截。

### 2. 健保雲端 2.0 網頁外掛：自動置頂 GOT / GPT / Cr / eGFR
* 在 Chrome 或 Edge 開啟健保雲端查詢系統並點擊「請換卡再按我」時，外掛會自動擷取最新一筆 **GOT (AST)、GPT (ALT)、Creatinine（自動排除尿液肌酸酐）、eGFR（自動排除肺癌基因檢測）**，做成紅／橘／黃／綠醒目色條釘在網頁最上方。
* 支援「換卡自動翻查」：若偵測到「檢查與檢驗」頁籤有資料，會於背景點開擷取數值後切回原本用藥頁籤，並透過本機加密迴路（`127.0.0.1:18765`）同步點亮本機 Python 視窗的肝腎警示燈號。

## 三、 系統與環境需求

1. **作業系統**：Windows 10 / Windows 11。
2. **健保控制軟體 5.x**：本機已安裝健保讀卡機控制軟體 5.x（預設路徑 `C:\NHI\LIB\CSHIS.dll`）並已註冊 ActiveX 簽章元件 `CsHisX.nhicshisx.1`。
3. **硬體與卡片**：PCSC 智慧卡讀卡機，且看診電腦須同時在線備妥 **SAM 安全模組卡 ＋ 已完成 PIN 驗證之醫事人員卡（醫師或藥師卡） ＋ 病人健保卡**。
4. **網路環境**：可正常連線健保 VPN（`medcloudws2.nhi.gov.tw:443` 與驗章主機 `10.253.253.250:10100`）。
5. **Python 執行環境**：**必須使用 32 位元（x86）Python 3.13**（因健保 `CSHIS.dll` 與 `CsHisX` 皆為 32 位元元件，64 位元 Python 無法載入；32 位元版可與電腦原有 64 位元 Python 安全並存）。
6. **瀏覽器（選配外掛用）**：Microsoft Edge 或 Google Chrome。

## 四、 從零開始安裝與部署步驟

### 步驟 1：下載並安裝 32 位元 Python 3.13（可與現有 64 位元並存）
1. 前往 Python 官方 Windows 下載頁：[https://www.python.org/downloads/windows/](https://www.python.org/downloads/windows/)
2. 在 **Python 3.13** 區塊中，務必下載 **Windows installer (32-bit)**（檔名**不含** `amd64`，例如 `python-3.13.x.exe`）。
   *(註：若診間電腦因 VPN 無法連外網，請先由他機下載安裝檔再以隨身碟複製過來。)*
3. 雙擊執行安裝檔，直接點擊 **Install Now**。
   * ⚠️ **重要：畫面下方的 `Add python.exe to PATH` 請保持「不要勾選」**，避免覆蓋系統原本的 64 位元 Python 或影響其他程式，Windows 內建的 `py` 啟動器會自動管理多版本。
4. 安裝完成後，**重新開啟**一個 PowerShell 視窗，輸入以下指令確認 32 位元環境已就緒：
   ```powershell
   py -0p
   ```
   清單中出現 `-V:3.13-32` 即代表安裝成功。

### 步驟 2：安裝必要 Python 套件
在 PowerShell 執行以下指令（專門安裝至 32 位元環境，安裝過程出現 `not on PATH` 黃字警告屬正常現象，請直接忽略）：
```powershell
py -3.13-32 -m pip install requests pywin32
```

### 步驟 3：唯讀驗證本機健保元件載入（確認零報錯）
在 PowerShell 貼上以下指令按 Enter：
```powershell
py -3.13-32 -c "import os, ctypes, win32com.client; os.add_dll_directory(r'C:\NHI\LIB'); ctypes.WinDLL(r'C:\NHI\LIB\CSHIS.dll'); ax = win32com.client.Dispatch('CsHisX.nhicshisx.1'); print('元件載入成功，測試亂數:', ax.VPNGetRandomX())"
```
畫面印出 `元件載入成功，測試亂數:` 並附帶一串 20 碼英數亂數，即代表讀卡與簽章底層完全就緒。

### 步驟 4：產生並安裝 Chrome / Edge 雲端檢驗外掛（只需做一次）
1. 將本專案所有檔案下載解壓縮至慣用目錄（例如 `%USERPROFILE%\nhi-clinic-ddi-helper`）。
2. 在該目錄開啟 PowerShell 執行外掛建置腳本：
   ```powershell
   py -3.13-32 build_browser_ext.py
   ```
   完成後會於同目錄自動產生 `nhi_cloud_lab_ext` 資料夾。
3. 開啟診間瀏覽器載入外掛：
   * **Edge**：網址列輸入 `edge://extensions` ➔ 開啟左下角 **開發人員模式** ➔ 將視窗**最大化**（避免按鈕被擠出右側） ➔ 點擊 **「載入解壓縮」** ➔ 選取 `nhi_cloud_lab_ext` 資料夾。
   * **Chrome**：網址列輸入 `chrome://extensions` ➔ 開啟右上角 **開發人員模式** ➔ 點擊 **「載入未封裝項目」** ➔ 選取 `nhi_cloud_lab_ext` 資料夾。
4. 切回健保雲端 2.0 網頁按 `F5` 重新整理，網頁頂部出現 **「🧪 雲端肝腎快篩」** 色條即完成安裝。

### 步驟 5：啟動主程式與兩階段實測
1. 啟動主程式（或直接雙擊 `啟動健保雲端助手.bat`）：
   ```powershell
   py -3.13-32 nhi_ddi_clinic_5x.py
   ```
2. **階段一（官方測試模式驗證）**：勾選「官方測試模式 (`Z299999992`)」，於上方填入本院真實「機構代碼」與任一執業醫師真實「身分證字號」，勾選任意測試藥品按下查詢。確認上方腎功能亮橘紅燈、肝功能亮深紅燈、過敏亮深紅燈即代表 VPN 與驗證成功。
3. **階段二（正式看診與建立捷徑）**：
   * **取消勾選**「官方測試模式」，確認「啟用讀卡槽自動感應」已打勾。
   * 點擊視窗第一區右側的 **「📌 建立桌面無黑框捷徑」**，關閉 PowerShell，之後一律雙擊桌面捷徑啟動。
   * *(選配)* 按 `Win + R` 輸入 `shell:startup`，將桌面捷徑複製進去即可開機自動常駐待命。

## 五、 常用操作快捷鍵與藥品清單維護

### 快捷鍵一覽
* **`Alt + F9`**：全域快捷鍵（在 HIS 系統打病歷時也能一鍵喚出視窗並立即重讀卡片）。
* **`F9`**：於本程式視窗內立即手動重查。
* **`Esc`**：快速將視窗縮小至工作列。

### 常用藥品清單（`config_clinic_drugs.json`）維護規則
程式啟動後會在同目錄自動產生 `config_clinic_drugs.json`（也可點擊視窗內「📂 開啟藥品 JSON 設定」直接編輯）：
* **`code`（10 碼健保藥品代碼，如 AC / AB / BC 碼）：必填且不可錯誤**。健保署 API 僅認現行有效之 10 碼健保醫令代碼，不可填成分英文名或 ATC 碼。
* **`name`（顯示名稱）：自由填寫**，僅供介面閱讀，不會傳送給健保署。
* **`category`**：西藥填 `"08"`，中藥填 `"09"`。
* 💡 **自費藥／已退健保原廠藥查詢秘訣**：健保署後端係將 10 碼健保碼轉換為 ATC 主成分比對 DDI，因此只需填入一顆**同成分、同劑型且仍在健保給付內的學名藥 10 碼健保碼**，交互作用比對結果將完全一致。

## 六、 常見異常碼排除與注意事項

| 回傳代碼 / 現象 | 原因與排除方式 |
| :--- | :--- |
| **代碼 `02`** | 三卡簽章驗證失敗：確認 SAM 卡、醫師卡（已完成 PIN 認證）與病人健保卡皆插妥。 |
| **代碼 `05`** | 醫令代碼已停用或不在健保署當期適用範圍：本程式已內建自動拆單隔離與 NSAID 探測碼自動輪替，僅會略過異常藥碼並提示刪除，不影響其餘警示顯示。 |
| **代碼 `09`** | 非本院專兼任醫師／藥師：測試模式下請檢查「機構代碼」與「醫師身分證字號」是否與院所執業登記相符。 |
| **網頁顯示 `⚪ 僅網頁顯示`** | 本機 Python 主程式尚未開啟；開啟桌面捷徑後，下次查詢即會自動轉為 `🟢 已同步桌面視窗`。 |

> **免責聲明**：本工具僅作為臨床處方前之資訊輔助與主動提醒用途，不取代醫師專業臨床判斷；開立具肝腎毒性或高風險交互作用藥物前，仍請以健保署官方雲端查詢畫面與完整病歷資訊為最終依據。
